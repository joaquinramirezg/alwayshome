# Proposed rebuilding-cost estimator contract

Design only, version `rebuild-design-v1`, 2026-11-06. No executable schema or
estimator is implemented. See [methodology](rebuilding_cost_methodology.md) and
[source register](rebuilding_cost_sources.md). This extends the proposed `assess`
contract conceptually; it does not change that contract or application code.

## Input fields

A required field must be present; `null` means unknown and triggers the applicable
completeness/review rule. Numeric unknowns are never encoded as zero. Homeowner
“Unknown” categorical answers map to unknown, not a construction class.

| Path | Type / units | Requirement and semantics |
|---|---|---|
| `schema_version` | string | Required version identifier. |
| `address` | string | Reuse existing contract. |
| `location` | object | `county_fips`, `zip`, `lat`, `lon`, `permitting_jurisdiction`, `jurisdiction_verified`; identifiers are strings. County must be confirmed LA (`06037`) for numerical MVP eligibility. |
| `home.dwelling_type` | enum | `detached_site_built_single_family`, `condominium`, `manufactured`, `multifamily`, `other`, `unknown`; gate supported scope. |
| `home.unit_count` | integer or null | Confirm single dwelling; multiple units require review. |
| `home.living_area_sqft` | positive decimal or null | Reuse existing contract; total finished living area across all stories. |
| `home.area_definition` | string or null | Living/finished area convention; must align to rate denominator. |
| `home.stories` | positive decimal or null | Reuse existing contract; allow documented split/partial floors. |
| `home.year_built` | integer or null | Reuse existing contract; plausible year checked against estimate date. |
| `home.major_renovation_years` | integer array | Optional; unknown distinguished from confirmed none. |
| `home.construction_type` | string or null | Framing/system description supported by source. |
| `home.foundation_type` | string or null | Slab, crawlspace, basement, engineered system, or unknown; no automatic salvage credit. |
| `home.quality` | object | `source_category`, `description`, `homeowner_confirmed`; do not map vague categories to unsupported multipliers. |
| `home.materials` | object | Reuse roof/exterior inputs from current home questionnaire, with explicit mapping and confirmation; do not equate siding with framing. |
| `home.features` | object array | Feature type, attached/detached, quantity, unit and area; includes garages, porches/decks, basement and unusual/custom work. State whether included in living area and cost source. |
| `site` | object | Slope/access, utility/septic, foundation reuse evidence, contamination and historic/coastal restrictions; each `confirmed`, `unknown`, or documented value. |
| `estimate_context` | object | Required `estimate_as_of`, `target_price_date`, `rebuild_scope`, `market_scenario` (`ordinary_current`, `disaster_current`, `future_stress`), `permit_date_assumption`, `currency` (`USD`). Dates ISO 8601. |
| `cost_evidence` | array | Required for calculation; rate/quote records described below. No default evidence generated by an AI model. |
| `cost_items` | array | Category records described below, for each offered scenario. |
| `field_provenance` | object keyed by input path | Evidence type, document/source reference, observed date, original value and confirmation state. Conflicts retained for review. |
| `insurance` | object, optional | Existing dwelling limit and endorsements may be passed through for later use; must not affect reconstruction pricing. |

Detailed optional quantities become required when the selected evidence needs them.
Absent material, quality or site information is not assumed typical. It can be
covered by an explicit scoped quote or marked for clarification/professional review.

## Cost evidence record

| Field | Type / purpose |
|---|---|
| `evidence_id`, `source_id` | Unique strings linking to source register or a private homeowner quote reference. Do not store policy documents in Git. |
| `source_url_or_document_ref`, `page_table` | Exact provenance and location within source. |
| `publication_date`, `price_base_date`, `retrieved_date` | Separate ISO dates or explicit unknown; price base must be resolved to use a rate. |
| `verification_status` | `full_document_verified`, `indexed_extract_only`, `unverified`; separate from parameter approval. |
| `parameter_status` | `context_only`, `pending_review`, `approved_for_this_scope`, `rejected`. Context-only sources cannot drive totals. |
| `reviewer`, `reviewed_at`, `valid_through` | Approval/freshness policy, to be decided before implementation. |
| `geographic_scope`, `property_scope`, `size_band`, `construction`, `quality`, `stories` | Applicability metadata and mismatch notes. |
| `unit` | `USD_per_finished_sqft`, `USD_lump_sum`, or `index_points`; other quantities explicitly typed. |
| `scenario_values` | `low`, `central`, `high`, each decimal or null; no generated midpoint. |
| `includes`, `excludes`, `unknown_scope` | Category arrays, including foundation, attached features, taxes, overhead/profit, fees, professional services and code work. |
| `market_conditions`, `limitations`, `reuse_permission` | Record disaster-market inclusion and licensing/privacy restrictions. |
| `location_adjustment`, `time_adjustment` | Factor, source ID, dates, applicable categories, reason and approval; null if needed but unsupported. |

## Cost item record

Each material category must appear in each offered scenario, even if unresolved.
A combined quote may cover several categories, but references must prevent adding
the same scope twice.

- `item_id`, `scenario`, `category`, `description`.
- `category`: construction, contractor_overhead_profit, demolition_debris,
  professional_services, permits_agency_fees, incremental_code,
  extraordinary_site_utilities, incremental_disaster_pressure, contingency.
- `scope_state`: `included_in_base`, `separately_priced`,
  `not_applicable_verified`, `unresolved`.
- `amount_usd`: nonnegative decimal for separately priced scope; null for unresolved.
  An embedded item can carry no separate increment while referencing its containing
  item. Confirmed inapplicable items need a reason; zero is not a missing-data flag.
- `evidence_id`, `included_in_item_id`, `cost_component_tags`, `policy_bucket_hint`.
- `quantity`, `quantity_unit`, `unit_rate`, if applicable; an overhead percentage
  also requires explicit `eligible_base_item_ids` and source evidence.
- `assumption_flag`, `assumption_description`, `approval_status`, `uncertainty_notes`.

Suggested nonbinding policy bucket hints: `dwelling`, `debris`, `ordinance_law`,
`other_structure`, `excluded_or_review`. Actual policy wording can override these;
hints are not a benefits determination. Other-structure and excluded budgets are
separate from the core R total unless the scope is deliberately revised.

## Output fields

| Path | Type / semantics |
|---|---|
| `method_version`, `generated_at`, `estimate_as_of`, `currency` | Audit identity and USD price date. |
| `status` | `complete_planning_estimate`, `needs_property_inputs`, `needs_cost_evidence`, `incomplete_scope`, `out_of_scope`, or `professional_review_required`. |
| `confirmed_inputs` | Values actually used and their provenance, plus jurisdiction and area convention. |
| `scenarios` | Object with `low`, `central`, `high`; absent evidence produces null scenario, not zero or copied central. |
| `scenarios.<s>.reconstruction_total_usd` | R for complete scope; null if material costs unresolved. |
| `scenarios.<s>.known_cost_subtotal_usd` | Optional partial arithmetic subtotal; clearly labeled incomplete, never used as a complete rebuild estimate. |
| `scenarios.<s>.construction_subtotal_usd` | H, with embedded-cost ledger. |
| `scenarios.<s>.component_totals` | Reconciled nonoverlapping cost categories and policy-bucket hints. |
| `scenarios.<s>.price_basis`, `evidence_ids`, `adjustments` | Source dates, rate/area, location/time factors and disaster inclusion. |
| `scenarios.<s>.completeness`, `unresolved_categories`, `assumptions` | Explicit scope and uncertainty. |
| `uncertainty` | Qualitative evidence quality, price/property/scope/site uncertainties, bound rationale; no probability/confidence level without calibration. |
| `missing_inputs`, `review_flags`, `excluded_costs` | User-actionable gaps, unsupported property classes and exclusions. |
| `assistance` | Separate documented fee waivers/program benefits, eligibility and dates; not silently netted from R. |
| `coverage_comparison_ready` | False unless cost scope is complete and separately reconciled to reviewed policy coverage. No gap result in this design. |
| `display_note` | “Planning estimate of reconstruction cost excluding land; not an insurer-certified replacement-cost valuation.” |

## Contract behavior

All money is nominal USD at the declared target price date. Preserve calculation
precision internally; display rounding is a later product decision. Reject negative
areas/costs, incompatible currencies/units, unapproved numerical benchmarks and
inconsistent inclusions. Do not use index points as USD/ft². Validate offered
scenario totals in order without manufacturing missing endpoints. A range is not
a confidence interval. If evidence is missing, the app can still finish with a
checklist and a missing-evidence explanation, without a dollar total.
